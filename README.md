# CM Island — site et espaces

Dépôt privé appartenant à Emma Tranchant EI (CM Island). Ne jamais le rendre public.

## Contenu

| Dossier | Rôle |
|---|---|
| `site/` | Site public cmisland.com, prêt à être mis en ligne (pages HTML générées) |
| `source/site/` | Sources du site : un fichier par page (`*.body.html`), la feuille de style et le script `build.py` qui génère `site/` |
| `espace/` | espace.cmisland.com : portails clients et Bureau admin (en construction, voir le doc 52 du projet CM Island) |

## Règles

- Aucun mot de passe, aucune clé, aucun IBAN ni lien de paiement dans ce dépôt.
- Toute modification passe par ce dépôt : la mise en ligne se fait automatiquement à partir de lui.
- Une notice détaillée (comment ajouter un client, modifier le modèle, restaurer une sauvegarde) sera ajoutée avec l'espace.
